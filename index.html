04

观影备忘：九条常见问题与说明

这里只回答本站定位、资料来源与放映信息的问题。影片推荐与观看渠道不在本站讨论范围内。
Q1
可可影视是做什么的？本站定位
+

这是一个影片资料与观影备忘站点，整理影片资料、分类索引、放映安排与观影备忘四类内容。

本站不提供在线观看与下载，不托管任何视频文件，也不提供网盘链接。如需观看，请通过正规渠道自行查询。

Q2
资料条目是怎么来的？资料来源
+

条目由资料组与热心读者共同整理，来源包括公开映后资料、片方公告与个人观影记录。

年份、片长与地区信息以片方公告为准。若发现错误，可通过提交资料入口反馈，我们会在一周内核对更新。

Q3
分类是怎么分的？分类依据
+

按影片类型与地区交叉分类，共十二类。同一部影片可能出现在多个分类下，以主要类型为准。

例如一部华语悬疑片会同时出现在「悬疑犯罪」与「华语片」下，但只在一个分类里写详细备忘。

Q4
放映安排准确吗？排期说明
+

信息来自各影院与放映空间的公开排片，本站只做整理，不负责售票，也不保证场次不变。

时间与票价请以放映方公告为准。临时取消或改期的场次，我们会尽量在 24 小时内更新。

Q5
观影备忘写的是什么？备忘内容
+

是看片时的随记：适合什么心情看、需要注意什么、看完想和谁讨论。不是影评，也不打分。

目前累计 386 条，均为个人视角，不代表客观评价。如果你有不同看法，欢迎在提交资料入口补充。

Q6
可以在这里找观看渠道吗？观看渠道
+

不可以。本站不提供任何在线观看、下载、网盘或资源链接，也不回答此类问题。

请通过影院、流媒体平台或正规音像渠道自行查询，支持正版。

Q7
如何提交新的影片资料？提交方式
+
  • 通过提交资料入口填写片名、年份、地区、分类与一段备忘。
  • 片名请使用片方公告的正式译名，不要使用网络别名。
  • 缺少的信息可以留空，我们会标注为「待补资料」。
  • 重复条目会被合并，合并后保留更完整的那份。
Q8
资料多久更新一次？更新频率
+

影片资料每周更新一次，放映安排每周一更新下周排期，观影备忘随看随写。

目前为第 35 辑，累计 1248 条资料条目。更新记录可在提交资料栏目的核对说明里查看。

Q9
我有其他问题该问谁？问题分流
+

本站定位、资料来源、分类依据与放映信息的问题都可以在这里找到答案。

影片推荐、观看渠道与版权投诉不在本站处理范围内。如需联系资料组，可通过顶部与页脚的咨询入口。

05

本站说明：四条需要提前知道的事

这段比栏目内容更重要。如果你只打算看一段，建议看这里。
NOTE 01

不提供观看与下载

本站不托管任何视频文件，不提供在线观看、下载、网盘或资源链接。所有内容仅为信息整理。

NOTE 02

排期以放映方为准

放映安排来自公开排片，本站只做整理，不负责售票。时间与票价请以放映方公告为准。

NOTE 03

备忘是个人视角

观影备忘是看片随记，不打分也不做评价。不同读者可能有完全不同的感受，仅供参考。

NOTE 04

资料可纠错可补充

年份、片长与地区信息可能有误，欢迎通过提交资料入口反馈，我们会在每周更新时一并核对。

SUBMIT

  • 片名请使用片方公告的正式译名，不使用网络别名
